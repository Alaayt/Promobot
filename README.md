# بوت البروموكود الذكي (Telegram Promo Bot)

بوت تليجرام بياخد أي صورة تبعتها له + بروموكود، وبيحط الكود تلقائياً في **أفضل مكان فاضي** في الصورة (من غير ما تحدد المكان يدوياً).

## 🧠 إزاي بيشتغل التموضع الذكي؟

البوت بيستخدم نظام على مرحلتين عشان يوصل لأدق نتيجة ممكنة:

### المرحلة 1: الذكاء الاصطناعي (Groq Vision) - تقدير أولي
لو القوالب اللي بتشتغل عليها فيها **صندوق مخصص فعلياً للكود** (زي قوالب 1xBet، أو أي بانر فيه حقل "استخدم الكود الترويجي")، البوت بيبعت الصورة لموديل رؤية (Vision Model) عبر Groq (مجاني)، وبيسأله يحدد إحداثيات الصندوق ده تقريباً.

### المرحلة 2: التدقيق المحلي (Local Refinement) - تصحيح الدقة
موديلات الرؤية بتقدّر الإحداثيات تقريباً، مش بدقة بكسل مثالية - فممكن تحط الكود قريب من الصندوق مش بالظبط جواه. عشان كده البوت بيعمل خطوة تدقيق محلية بالكود (مفيش أي API تانية، كله محلي وسريع):
1. **ارتكاز:** بيدور جوه تقدير الـ AI على أصغر نقطة "مسطحة" (تباين لوني شبه صفر) - ده بيمسك نقطة إحنا متأكدين إنها جوه الصندوق فعلاً
2. **توسيع:** بيوسّع المستطيل من النقطة دي لكل الاتجاهات، طول ما الألوان المجاورة لسه قريبة - وده بيرسم حدود الصندوق الحقيقية تلقائياً، حتى لو تقدير الـ AI كان فيه إزاحة أو حجم غير دقيق

### المرحلة 3: تحليل الشبكة (Grid Analysis) - احتياطي أخير
لو الصورة عادية (مفيهاش صندوق مخصص، زي صورة منتج أو خلفية عادية)، أو لو الذكاء الاصطناعي مش متاح (مفيش `GROQ_API_KEY`)، أو التدقيق المحلي مقتنعش بأي نتيجة منطقية، البوت بيرجع للطريقة الاحتياطية الأصلية:
1. بيقسم الصورة لشبكة (grid) افتراضياً 4×4
2. بيحسب "التباين اللوني" (variance) في كل خلية
3. الخلية اللي تباينها قليل (منطقة مسطحة/بسيطة) = أنسب مكان للنص
4. بيفضّل الصفوف السفلية شوية (مكان شائع للبروموكودات) من غير ما يمنع اختيار مكان تاني لو أنسب

في كل الحالات، البوت بيحدد لون النص (أبيض/أسود) تلقائياً حسب سطوع المنطقة المختارة، ويضيف حدود (stroke) عكسية عشان يبقى واضح مهما كانت الخلفية.

> 💡 **الخلاصة:** الذكاء الاصطناعي بيدّي فهم عام لمكان الصندوق، والتدقيق المحلي بيحوّل الفهم العام ده لإحداثيات دقيقة بالبكسل - من غير ما نحتاج أي API إضافي مدفوع.

```
│   └── utils/
│       └── logger.js
├── .env.example
├── package.json
└── README.md
```

## 🚀 خطوات التشغيل (خطوة بخطوة)

### 1. إنشاء البوت من BotFather

1. افتح تليجرام وابحث عن `@BotFather`
2. ابعتله `/newbot`
3. اختار اسم للبوت، وبعدها username (لازم ينتهي بـ `bot`)
4. هيديك **توكن** (Token) شكله كده: `123456789:ABCdefGhIJklmNoPQRstuVWXyz`
5. احتفظ بالتوكن ده، هتحتاجه في الخطوة الجاية

### 2. (اختياري لكن موصى به) تفعيل الذكاء الاصطناعي للدقة العالية

1. سجل مجاناً على [console.groq.com](https://console.groq.com)
2. من قائمة **API Keys** اعمل مفتاح جديد
3. احتفظ بيه، هتحطه في `.env` في الخطوة الجاية

> بدون المفتاح ده، البوت هيشتغل تمام لكن بطريقة الشبكة الاحتياطية بس (أقل دقة مع القوالب اللي فيها صناديق كود مخصصة زي 1xBet).

### 3. تجهيز المشروع محلياً

```powershell
# فك الضغط عن المشروع، وبعدين ادخل المجلد
cd telegram-promo-bot

# ثبت المكتبات
npm install

# اعمل نسخة من ملف البيئة
Copy-Item .env.example .env
```

افتح ملف `.env` وحط التوكن اللي اخدته من BotFather:

```
BOT_TOKEN=123456789:ABCdefGhIJklmNoPQRstuVWXyz
NODE_ENV=development
GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxx
```

### 4. تشغيل البوت محلياً

```powershell
npm start
```

لو شغال صح هتشوف في الترمينال:
```
[INFO] ... البوت شغال دلوقتي ✅
```

دلوقتي افتح البوت في تليجرام وابعتله `/start` جرب.

## ☁️ رفع البوت على Railway

1. ادخل على [railway.app](https://railway.app) وسجل دخول
2. اعمل **New Project** → **Deploy from GitHub repo** (لازم ترفع المشروع على GitHub الأول) أو **Empty Project** وبعدين اربطه بـ CLI
3. من تبويب **Variables** في المشروع، ضيف:
   - `BOT_TOKEN` = التوكن بتاعك
   - `NODE_ENV` = `production`
   - `GROQ_API_KEY` = مفتاح Groq بتاعك (لو عايز الدقة العالية بالذكاء الاصطناعي)
4. Railway هيكتشف تلقائياً إنه مشروع Node.js وهيشغل `npm start`
5. تأكد إن الـ **Start Command** في الإعدادات هو: `npm start`

> ⚠️ **مهم:** البوت شغال حالياً بنظام Polling (مش Webhook)، يعني لازم يفضل شغال باستمرار على Railway (مش Serverless function). ده الوضع الافتراضي المناسب لخطتك.

## 🧪 اختبار سريع من غير تليجرام (اختياري)

عايز تتأكد إن خوارزمية التموضع شغالة صح قبل ما تربط البوت؟ جرب السكريبت ده:

```powershell
node -e "const {generatePromoImage}=require('./src/controllers/promo.controller');const fs=require('fs');(async()=>{const img=fs.readFileSync('test-image.jpg');const result=await generatePromoImage(img,'SAVE20');fs.writeFileSync('output.png',result);console.log('تم! افتح output.png')})()"
```

(غيّر `test-image.jpg` بأي صورة عندك في نفس المجلد)

## ⚙️ إعدادات ممكن تعدلها

في ملف `.env`:

| المتغير | الوصف | القيمة الافتراضية |
|---|---|---|
| `GRID_COLS` | عدد أعمدة شبكة التحليل | 4 |
| `GRID_ROWS` | عدد صفوف شبكة التحليل | 4 |

زيادة الأعمدة/الصفوف = دقة أعلى في اختيار المكان، بس تحليل أبطأ شوية (الفرق غير محسوس عملياً).

## 📝 ملاحظات مهمة

- **دعم اللغة العربية في البروموكود:** الخط الحالي (`Arial`) بيدعم إنجليزي/أرقام بشكل ممتاز. لو هتحتاج تكتب بروموكود بالعربي، هتحتاج تثبت خط عربي على السيرفر (زي `Amiri` أو `Noto Naskh Arabic`) وتغيّر `font-family` في `imageEditor.service.js`.
- **الذاكرة المؤقتة (Session):** حالياً بتتخزن في الذاكرة (`Map`) - لو البوت اشتغل على أكتر من نسخة (instance) في نفس الوقت هتحتاج تستبدلها بـ Redis. لمشروع بحجم بوت واحد على Railway، الوضع الحالي كافي تماماً.
- **حجم الصور:** تليجرام بيضغط الصور اللي بتتبعت كـ "photo" تلقائياً. لو عايز جودة أعلى (بدون ضغط)، تقدر تعدّل البوت يستقبل الصور كـ "document" بدل "photo".

## 🔧 لو حصل مشكلة

| المشكلة | الحل |
|---|---|
| `BOT_TOKEN مش موجود` | تأكد إنك عملت `.env` مش بس `.env.example` |
| البوت مش بيرد | تأكد إن التوكن صحيح ومفيش مسافات زيادة |
| الكود بيتحط في مكان غلط رغم وجود صندوق واضح في الصورة | تأكد إن `GROQ_API_KEY` متحط صح في `.env`. لو مش متحط، البوت هيستخدم طريقة الشبكة الاحتياطية اللي أقل دقة مع القوالب الجاهزة |
| موديل الرؤية بيرجع خطأ أو نتيجة غريبة | موديلات Groq بتتغير بين فترة وفترة - افتح `src/services/aiVision.service.js` وحدث قيمة `VISION_MODEL` حسب [الموديلات المتاحة حالياً](https://console.groq.com/docs/vision) |
| الصورة بتطلع من غير كود واضح (صور عادية بدون صندوق) | جرب صورة تانية فيها منطقة سادة أوضح، أو زوّد `GRID_COLS`/`GRID_ROWS` لدقة أعلى |
